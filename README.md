# Python Day 140 - Expense Tracker

## Description
An intermediate Python project that allows users to record expenses, view saved records, and calculate total spending. Expense data is stored in a CSV file for future use.

## Features
- Add an expense with category, amount, and description
- View saved expenses
- Calculate total expenses
- Store records persistently in a CSV file
- Handle invalid amount input

## Concepts Used
- Functions
- File Handling
- CSV Module
- Exception Handling
- Loops and Conditional Statements
- Date Module

## Files
- `expense_tracker.py` - Main application
- `expenses.csv` - Automatically created data file

## How to Run
1. Install Python 3.
2. Run `python expense_tracker.py`.
3. Select an option from the menu.
4. Add expenses and view your records.
